Understanding the curve equation

An elliptic curve over a prime finite field is defined by:

y² = x³ + ax + b (mod p)

Here, p is a prime number, a and b determine the shape of the curve, and x and y are integers between 0 and p − 1. All calculations are performed modulo p, meaning that results wrap around after reaching p.

Checking whether a point is on the curve

Consider our toy curve y² = x³ + 2x + 2 (mod 17). We can verify that G = (5, 1) belongs to it:

  1. Left-hand side: y² = 1² = 1.
  2. Right-hand side: 5³ + 2(5) + 2 = 137.
  3. Reduce modulo 17: 137 mod 17 = 1.
  4. Both sides equal 1, so (5, 1) is on the curve.

Why the curve must be non-singular

For the equation y² = x³ + ax + b, the curve must satisfy (4a³ + 27b²) mod p ≠ 0. This prevents singularities (cusps and self-crossings) and makes the group operations well-defined.

For our toy curve, a = 2 and b = 2: 4(2³) + 27(2²) = 32 + 108 = 140, and 140 mod 17 = 4, which is not zero. So the curve is non-singular.

The point at infinity

Elliptic curves include a special point called the point at infinity, written O. It acts as the identity element for point addition: P + O = P.

Every point P = (x, y) has an inverse −P = (x, −y mod p), with P + (−P) = O. For example, on our curve (5, 1) and (5, 16) are inverses because 1 + 16 = 17, which is zero modulo 17.

These properties make the curve's points a mathematical group, which is the foundation of elliptic-curve cryptography.

The group law: adding points

Point addition: P + Q

Suppose P = (x1, y1) and Q = (x2, y2) are two different points on the curve, with x1 ≠ x2. First calculate the slope:

λ = (y2 − y1) · (x2 − x1)⁻¹ mod p

Then the result R = (x3, y3) is:

x3 = (λ² − x1 − x2) mod p
y3 = (λ(x1 − x3) − y1) mod p

The notation ⁻¹ is a modular multiplicative inverse, not ordinary division.

Worked example: 3G

On our toy curve, G = (5, 1) and 2G = (6, 3). To calculate 3G, add these two points:

  1. Slope: λ = (3 − 1) · (6 − 5)⁻¹ mod 17 = 2.
  2. x3 = (2² − 5 − 6) mod 17 = −7 mod 17 = 10.
  3. y3 = (2(5 − 10) − 1) mod 17 = −11 mod 17 = 6.

Therefore, 3G = (10, 6).

Point doubling: 2P

When adding a point to itself, use the tangent slope instead of the chord slope. For P = (x1, y1), provided y1 ≠ 0:

λ = (3x1² + a) · (2y1)⁻¹ mod p

The coordinates then follow from the same x3 and y3 formulas.

Worked example: 2G

Let G = (5, 1), a = 2 and p = 17.

  1. Numerator: 3(5²) + 2 = 77.
  2. Denominator: 2(1) = 2. Its inverse modulo 17 is 9, because 2 · 9 mod 17 = 1.
  3. λ = 77 · 9 mod 17 = 13.
  4. x3 = (13² − 5 − 5) mod 17 = 6.
  5. y3 = (13(5 − 6) − 1) mod 17 = 3.

Therefore, 2G = (6, 3).

Special cases

  • Adding O to any point P returns P.
  • Adding a point to its inverse returns O.
  • Doubling a point whose y-coordinate is zero returns O.
  • Modular division is only possible when the denominator has an inverse modulo p.

Scalar multiplication and double-and-add

Scalar multiplication means repeatedly adding a point to itself: Q = k·G, where k is a whole number (a scalar). For example 1G = (5, 1), 2G = (6, 3), 3G = (10, 6), 4G = (3, 1), 7G = (0, 6). The table on this step lists every multiple of G for the toy curve.

Adding G to itself k times would be far too slow for the huge k of real curves. Instead, double-and-add writes k in binary and combines doublings with additions.

Worked example: 7G

7 is 111 in binary, so 7G = 4G + 2G + G:

  1. Start with G = (5, 1).
  2. Double G to obtain 2G = (6, 3).
  3. Double 2G to obtain 4G = (3, 1).
  4. Add 4G and 2G to obtain 6G = (16, 13).
  5. Add G to 6G to obtain 7G = (0, 6).

Double-and-add needs only about 2 · (number of bits of k) group operations, so even a 256-bit scalar takes a few hundred steps. The Keys page shows every one of these steps for your own key.
